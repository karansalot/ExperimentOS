## Findings

- **No missing or non-finite values** (note). All 16 columns are complete and every binary column contains only 0/1.
- **No user identifier or timestamp** (note). Rows are described as users, but there is no key to verify uniqueness and no time dimension. Time-based checks (novelty, day-of-week, sequential testing) are not possible.
- **2,221,150 rows (15.9%) are exact duplicates of another row** (caution). Features are coarse and heavily concentrated, so identical rows can be distinct users. Without a user id they cannot be attributed, so they are reported and kept.
- **Row order is not random** (caution). 12 of 20 equal-size position blocks contain a single arm only, and block visit rates range from 2.24% to 8.63%. A sequential sample (e.g. the first N rows) or a head/tail split would be badly biased. All sampling and splitting here uses a salted hash of row position.
- **Outcome hierarchy holds** (note). Every conversion is also a visit, and no control user is marked as exposed.
